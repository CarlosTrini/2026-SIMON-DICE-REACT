# Simon Dice 
> Un juego clásico de simon dice con modo multijugador y diferentes dificultades
> En pantalla puedes ver:
> - ¿Qué jugador sigue?
> - Puntajes que tienen o tienes
> - Cantidad de jugadores
> - Número de ronda


## Demo 
> https://juego-simon-dice-react.netlify.app/

![alt text](/public/images/portada.png)

## Desarrollado con:
- React
- Context API
- TypeScript
- TailwindCSS
- Vite
- SweetAlert2
- Lucide React
- Canvas-conffetti


## Features
- Juego de Simon Dice en español
- Modo multijugador
- Diferentes niveles de dificultad
- Contador de puntos
- Secuencia de colores
- Botones interactivos
- Responsive
- Animación al ganar punto con conffetti
